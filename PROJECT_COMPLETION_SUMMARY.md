## Troubleshooting

### Issue: "PDF won't open in KDP"
**Solution**: Verify file is PDF 1.4 format. Convert using Adobe Reader or online converter.

### Issue: "File rejected for quality"
**Solution**: Check that PDF is pure black & white (no grays). Ensure 300+ DPI when viewed.

### Issue: "Margins too small"
**Solution**: Open PDF in Adobe Acrobat Pro and adjust margins, or regenerate Python script.

### Issue: "File size too large"
**Solution**: Current file is 78.4 KB (very small). If you add illustrations, compress images.

### Issue: "Text appears blurry in preview"
**Solution**: Ensure fonts are embedded. This is already done in the generated PDF.
